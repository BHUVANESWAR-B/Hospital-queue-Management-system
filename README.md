# Smart Hospital Queue Optimization System

## Overview
This project predicts patient waiting time and optimizes hospital queue using data science techniques.

## Dataset
Medical Appointment No Shows dataset (Kaggle)

## Features
- Waiting time prediction using ML
- Queue optimization using priority logic
- Data visualization

## Tools Used
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib

## How to Run
pip install -r requirements.txt
python app.py
